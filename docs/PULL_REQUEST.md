# Formato de pesos mexicanos en campos de importe

Muestra los importes como $153,900.00 y $118,097.70 al salir del campo. Al enfocarlo permite editar el número con teclado decimal. Acepta pegar cantidades con símbolo de pesos y comas de miles, y envía al formulario únicamente el valor numérico.

Aplica a movimientos, apertura de deudas, abonos, presupuestos y recurrentes. Conserva importes mínimos/máximos, límite de dos decimales y campos de apertura de solo lectura. No modifica los cálculos financieros ni IndexedDB.

Prueba de navegador para formato, edición, centavos, validación de sobrepagos y persistencia al recargar.

Validación: 34 pruebas unitarias y 28 pruebas de navegador aprobadas; compilación de producción correcta.
